- 2026-06-19 — PinPoint walk-mode coordinate-space contract (canonical — DO NOT REGRESS). The mini-map had a second "wrong tile content under the dot" bug after Step 2.6. Root cause: the prior code pretended (tap viewport-px at tap time) ≡ (bitmap viewport-px at capture time) — that equation only holds if qozix's scrollX/scrollY/mScale doesn't change between tap and `sheetView.draw(canvas)`. Any layout pass (banner dismiss, capture-view removal, fling-settle) in that window broke the assumption.
